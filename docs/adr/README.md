# Architecture Decision Records

One file per decision, numbered in order. A record states the context, the
decision, and what it costs us — including the costs, not only the benefits.

Write a new ADR when a choice would be expensive to reverse, when it constrains
future work, or when a reasonable person would ask "why is it done this way?".
Superseded records stay in place with their status changed; they are not
deleted.
