# SermonAI — keys for the service

The operator's one-page cheat sheet (PRD §13.18; the M3 exit gate's "printed
cheat sheet"). `cheat-sheet.pdf` beside this file is the print copy, generated
from `cheat-sheet.html` so it prints the same on any machine; regenerate it
with the command in that file's header whenever a key changes. Keep all three
and `src/windows/operator/components/stagingKeys.ts` in step.

Every key works with no text box selected. If a box has the cursor, click
anywhere empty first.

**The path:** Card (a verse the app heard) → Staged (you read it once more) →
Live (on the projector).

## Every service

| Key | Does |
|---|---|
| Enter | The next step. Nothing staged: stage the top card. Something staged: send it live. |
| Shift+Enter | Top card straight to the projector. |
| Esc | Clear the staged verse. The projector keeps what it has. |
| → / ← | Next or previous verse of the passage on the projector. |

## Finding a verse

| Key | Does |
|---|---|
| Ctrl+K | Search any verse. Type `john 3 16`. Enter stages it, Shift+Enter sends it live, Tab changes translation, Esc closes. |
| P | Pin the top card. Pinned verses stay all service, at the top of the list. |
| 1 … 9 | Send pinned verse 1 to 9 to the projector, any time, as often as needed. |

## If something is wrong

| Key | Does |
|---|---|
| B | **Blank the projector at once.** Press B again to bring the verse back. Nothing is lost. |
| Esc | Wrong verse staged? Clear it. It never reached the screen. |

**Before the service:** Live tab → choose the input → switch Transcribe on.
Cards appear on the right as scripture is spoken; a card nobody touches leaves
after 30 seconds. Auto-live off means nothing reaches the projector without
you.
